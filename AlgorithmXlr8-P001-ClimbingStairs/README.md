# Climbing Stairs

**Difficulty:** `Easy`

## Problem

You are climbing a staircase that takes n steps to reach the top. Each time, you can climb either 1 or 2 steps.

Return the number of distinct ways you can climb to the top.

Read n from standard input, and print the count of distinct ways to standard output.

## Examples

### Example 1

**Input**
```
n = 2
```
**Output**
```
2
```

**Explanation:** There are 2 ways: (1 step, 1 step) or (2 steps).

### Example 2

**Input**
```
n = 3
```
**Output**
```
3
```

**Explanation:** There are 3 ways: (1,1,1), (1,2), and (2,1).

### Example 3

**Input**
```
n = 1
```
**Output**
```
1
```

**Explanation:** There is only 1 way: a single 1-step.
